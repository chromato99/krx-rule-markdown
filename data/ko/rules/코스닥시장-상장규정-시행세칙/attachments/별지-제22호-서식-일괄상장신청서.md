일괄상장 신청서

(세칙 제40조제1항 관련)

한국거래소 이사장 귀하 신 청 일： 년 월 일

신청회사：

대표이사： (인)

「코스닥시장 상장규정」 제45조제1항에 따라 다음 신주의 상장을 신청합니다.

| 종 목 |  |
| --- | --- |
| 발행회차 |  |
| 1주의 금액(액면가)(원) |  |
| 1주의 발행가액(원) |  |
| 발행예정 주식 수(주) |  |
| 발행예정 총액(원) |  |
| 비 고 |  |

기재상의 주의

1. 종목에는 ㅇㅇ주식회사 보통주 및 우선주 등을 기재한다.

2. 발행회차에는 해당 주식등의 발행회차를 기재한다.

3. 발행예정 주식 수에는 전환권, 신주인수권 또는 주식매수선택권의 행사로 인하여 발행하기로 한 총 주식 수를 기재한다.
