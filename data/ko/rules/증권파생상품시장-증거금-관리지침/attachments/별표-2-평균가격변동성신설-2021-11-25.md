[별표 2] 평균가격변동성<신설 2021.11.25>

평균가격변동성

(제5조 및 제10조 관련)

수식 1 원본(HWP EqEdit):
```hwp-equation
평균~가격변동성( sigma _{avg,~t} )= sqrt {sum _{i=t-N+2} ^{t-1} "{"(r _{i} - {bar{r}} ) ^{2} /(N-3)"}"}# # {bar{r}} `= sum _{i=t-N+2} ^{t-1} "{"r _{i} /(N-2)"}"
```

수식 1 LaTeX(best-effort):
```math
\begin{aligned}\text{평균 가격변동성}(\sigma_{avg,t}) = \sqrt{\sum_{i = t - N + 2}^{t - 1} \{(r_{i} - {\bar{r}})^{2} /(N - 3)\}} \\ {\bar{r}} = \sum_{i = t - N + 2}^{t - 1} \{r_{i} /(N - 2)\}\end{aligned}
```

[수식 2 LaTeX(best-effort): \(N\)] : 직전 매매거래일로부터 과거 10년간 매매거래일 수.

수식 2 원본(HWP EqEdit):
```hwp-equation
N
```

수식 2 LaTeX(best-effort):
```math
N
```

[수식 3 LaTeX(best-effort): \(r_{t - n}\)] : [수식 4 LaTeX(best-effort): \(n\)] 매매거래일 전의 수익률. 이 경우 수익률은 해당 매매거래일의 해당 종목 또는 지수의 종가에서 2매매거래일 이전의 해당 종목 또는 지수의 종가를 차감한 값을 2매매거래일 이전의 해당 종목 또는 지수의 종가를 나누어 구한다.

수식 3 원본(HWP EqEdit):
```hwp-equation
r _{t-n}^{}
```

수식 3 LaTeX(best-effort):
```math
r_{t - n}
```

수식 4 원본(HWP EqEdit):
```hwp-equation
n
```

수식 4 LaTeX(best-effort):
```math
n
```

[수식 5 LaTeX(best-effort): \(\bar{r}\)] : 직전 매매거래일로부터 과거 10년간의 평균수익률.

수식 5 원본(HWP EqEdit):
```hwp-equation
bar {r}
```

수식 5 LaTeX(best-effort):

\bar{r}
